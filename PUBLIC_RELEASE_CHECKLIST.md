# Public release checklist

Before switching the GitHub repository from private to public:

- [ ] Confirm the final GitHub repository name and URL.
- [ ] Confirm the author list in `CITATION.cff`.
- [ ] Add the final article DOI/citation after publication.
- [ ] Add the final FinnGen release/endpoint to the manuscript Data Availability section if desired.
- [ ] Confirm that no restricted or redistributable-only-under-license GWAS files are included.
- [ ] Confirm that no GTEx BESD or 1000 Genomes genotype/reference files are included.
- [ ] Confirm that no credentials, tokens, passwords, or private server details are committed.
- [ ] Decide whether to add an open-source license.
- [ ] Optionally tag a release corresponding to the submitted or accepted manuscript version.
